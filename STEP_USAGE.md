# STEP.PY - Руководство по использованию

## Назначение
Программа для **ручного управления роботом** и **построения графа узлов** навигации. Позволяет исследовать карту, записывать ключевые точки (узлы графа) с их координатами и комментариями.

## Запуск
```bash
python step.py
```

## Управление

### Движение
- **↑** - движение вперёд на 0.5 м
- **↓** - движение назад на 0.5 м
- **→** - поворот вправо на 11.25° (π/16 радиан)
- **←** - поворот влево на 11.25° (π/16 радиан)
- **1/2/3/4** - малые шаги вперёд: 0.1 / 0.2 / 0.3 / 0.4 м

### Запись данных
- **W** - **ЗАПИСАТЬ УЗЕЛ ГРАФА**
  - Программа попросит ввести название узла
  - В лог запишутся: координаты (x, y), угол (th), название узла
  - Используйте для ключевых точек маршрута

- **C** - добавить текстовый комментарий в лог
  - Используйте для пометок между узлами
  - Пример: "проехал между паллетами", "вижу вход в коридор"

- **S** - скан (показать текущую телеметрию и данные лидара)

- **Q** - выход из программы

## Формат лога (step.log)

### Запись узла графа:
```
============================================================
[NODE] START
[NODE] pos=(0.00,0.00) th=0.0°
============================================================
```

### Телеметрия после движения:
```
[STEP] Команда: вперёд 0.50 м
[TELEMETRY] pos=(0.50,0.02) th=1.5°  F=2.34 L=1.23 R=3.45
[LIDAR] beams=90 ranges: 2.34, 2.35, 2.36, ...
```

### Комментарий:
```
[COMMENT] проехал мимо утки справа, впереди видна паллета
```

## Рекомендации по построению графа

1. **Стартовая позиция**: нажмите W и назовите узел "START"
2. **Выезд из кармана**: двигайтесь маленькими шагами (1-4), записывайте узел "EXIT_POCKET"
3. **Повороты**: после поворота на восток записывайте "TURN_EAST"
4. **Ключевые точки**:
   - "BEFORE_PALLETS" - перед паллетами
   - "BETWEEN_PALLETS" - между паллетами
   - "CORRIDOR_ENTRANCE" - вход в коридор
   - "ROOM2_ENTRANCE" - вход во вторую комнату
   - "FINISH" - финишная зона

5. **Между узлами**: используйте клавишу C для комментариев:
   - "вижу узкий проход справа"
   - "утка слева на расстоянии 0.5м"
   - "можно подрулить влево, чтобы объехать"

## Пример сценария использования

```
1. Запустить step.py
2. W -> "START" (записать стартовый узел)
3. ↑ ↑ ↑ (проехать вперёд 1.5м из кармана)
4. W -> "EXIT_POCKET" (записать узел выхода)
5. → → → → (повернуть вправо ~45°)
6. W -> "FACING_SOUTH" (записать ориентацию)
7. C -> "вижу южную стену на расстоянии 1.2м" (комментарий)
8. ↑ ↑ (проехать к стене)
9. W -> "NEAR_SOUTH_WALL" (записать узел)
... и так далее по всему маршруту
```

## Результат

После ручного проезда по маршруту в файле `step.log` будет:
- **Граф узлов** с координатами (x, y, th)
- **Комментарии** о препятствиях и проходах
- **Траектория** робота между узлами
- **Данные лидара** на каждом шаге

Эти данные можно использовать для:
1. Создания конечного автомата с известными узлами
2. Программирования точных траекторий
3. Настройки параметров навигации
4. Отладки логики объезда препятствий
